# 大肥鱼 · 全功能升级

> **DeepSeek Harness（DSH）增强装配的全功能升级开源版** —— 38 个插件 ＋ 6 个本地扩展件（带源码）组成的一体化 agent 工作台，配 **席位／记忆／路由／MCP** 内核与一条**可复刻的发行线**。
>
> 这是「多人格 AI 工作台」如何从零搭起的一份完整答卷：功能全貌、内核机制、版本治理与复刻步骤，尽在其中。

## 这是什么

把 DSH 从"能干活的 agent 框架"升级为**多位格协作工作台**的一套装配与机制说明。适用人群：

- 想在自己电脑上搭"多个 AI 各司其职、互相检查"的工作台的人；
- 对 **agent 记忆系统／多预设席位／MCP 工具接入／可复刻发行线** 的实现细节感兴趣的开发者；
- 想复刻一份"开箱接近成品"的一体化 agent 工作台的人。

> 协作侧（工作流与制度）独立一园：[多 Agent 协作工作流](https://github.com/rosalynthompson32-a11y/dafeiyu-studio-collab)（另见文末链接）。

## 内核机制（升级线 · 详版见 [docs/架构-DSH增强全景.md](docs/架构-DSH增强全景.md)）

- **预设／席位制**——多智能体预设按会话选择；各席各有档案与记忆空间；记忆跨会话、跨项目保留——「席换到哪，读的就是哪席的记忆空间」。
- **记忆系统**——宿主／客户端两层 ＋ 来源接入（摘要＋指针，原文不动）；可修剪、可改档。
- **多模型路由**——按席／按档位配模型；故障回退与成本护栏。
- **MCP 工具接入**——外部能力以标准协议即插即用。
- **技能管理**——多席共享同一技能目录；技能即知识包。
- **协作可见性**——实时日志 ＋ Web UI 直播 ＋ 执行轨迹面板。

## 发行线（工程严谨度）

| 件 | 职责 |
|---|---|
| `manifest.json` | 件集清单＋逐件 sha256＋集指纹 |
| `scan-artifacts.mjs` | 件集实取（口径＝三源并集） |
| `verify-release.mjs` | 守卫校验（改一字节→红 exit 1；复原→绿 exit 0） |
| `pack-release.mjs` | 打包对账（逐条含 sha256 全绿） |
| 发行台账 | 一行一次发行；回退＝追「回退行」 |

一次真实终版发行：**19 件／771 文件**逐条对账全绿，异常序全程留档，可追溯每一次打包。

## 快速复刻

1. **准备**：Windows 10/11；Node.js 22+；`npm install -g pnpm`；
2. **装本体**：`npm install @deepseek-ai/dsh@0.2.0-rc.2`，首启并按提示配置你自己的 API Key（费用自理）；
3. **部署增强包**：解压后运行 `setup.ps1`（自动链接本地扩展件、铺 profile 与皮肤参数）；
4. **按需配置**：预设／记忆／路由／技能，运行 web 或 headless profile。

> 增强装配**不含**：任何凭据、账号、会话历史、任务数据与个人化配置。
